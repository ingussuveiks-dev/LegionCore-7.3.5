# Augstākā kvesta kartes koordinātas

`LoadQuestPOI` izlaida arī lielāko ID, kuram jau bija paredzēta vieta koordinātu masīvā. Darba datubāzē tas bija 20. līmeņa `Stranger in a Strange Land` (`50319`). Zondē ar ieslēgtu POI diagnostiku sākotnējais ielādētājs ziņoja par visām trim trūkstošajām atzīmēm. Pēc salīdzinājuma labojuma ielādējās visi trīs sākotnējie Orgrimmar punkti.
