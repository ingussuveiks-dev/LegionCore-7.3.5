# Argus quest map points

The live world database had Legion 7.3.5 quest POI definitions without coordinates throughout Krokuun, Mac'Aree and Antoran Wastes. This migration supplies 2,055 coordinates for 1,068 existing definitions across 318 quests. Coverage includes the route to Argus, some related instances, and the surface and Vindicaar deck variants. The earlier migrations handle Threat Reduction, Prisoners No More and the existing Hand of Fate Horde and Army of the Light points.

The coordinate source is the local TrinityCore `2019_03_27_00_world.sql` 28153 archive for 1,830 points and the later `2023_11_15_11_world_quest_poi.sql` 52106 archive for 225. The archive definition had to match the local quest, blob and point-set indices, objective index, objective and object IDs, map, mapped UI area and floor, player condition, spawn tracking and merging behavior. The migration retains the live definitions and rechecks their fields before inserting a complete missing point set. Where 52106 coordinates match, the point row uses build 0 because the local build field is signed SMALLINT. The unrelated quest 33800 was excluded.

The next Krokuun route was reviewed against the local Turalyon and Vindicaar spawns. The coordinates include the talk and kill objectives for A Strike at the Heart, the upper-deck Alleria turn-in for Return to the Vindicaar, and the different decks and surface locations used by A Moment of Respite and Gathering Light. For Gathering Light the later archive's turn-in at 1084, 2274 agrees with the first Xenedar receiver at 1082.96, 2274.30.

With the player logged out, the SQL ran in connection-local shadow tables. The initial execution inserted exactly 2,055 rows, and a repeat preserved that count. Separate shadow fixtures retained a custom point set, skipped a changed player condition, and skipped an ambiguous blob index. Diagnostic snapshots showed no new crash files, server warnings or errors, or appended database errors. The live database and server process were left in place. The updater and marker rendering in the client remain pending.
