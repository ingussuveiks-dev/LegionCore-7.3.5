# Map guidance for the Legion Twins quest chain

The user could accept and turn in the quests, but the map supplied no usable coordinates. The runtime database had 45 `quest_poi` definitions across these 16 quests and no linked `quest_poi_points`. The quest map handler reads the stored blobs and coordinates. Creature quest relations provide a separate NPC marker.

Migration `2026_11_23_10` restores 78 coordinates across the introduction (46765 and 47034), all five selection quests leading into the same Twins chain (45182, 47037, 47039, 47041 and 47042), its six shared steps (45185, 45187, 45188, 45190, 45192 and 45193), and its ending and challenge (45866, 46127 and 45910). The points supply the investigation search region, the inn upstairs and downstairs, the original Underbelly search polygon, Felbreach Hollow, the return to the Violet Citadel, War Councilor Victoria at Mage Tower and the final hand-in. The moving Karam turn-in uses the original Underbelly map region, not a new fixed spawn.

The point source is the local TDB 735.00 archive, whose matching coordinates were captured at build 24330. Untouched points retain that build. Ten coordinates that guide players back to Karlain use his existing Violet Citadel role spawn (entry 90463, spawns 272739 and 377283). The two older Investigating the Legion definitions use copies of the native start point and search polygon. Their replacement points and the local Karlain pins use build 0. The gated search polygon originally shared Idx1 2 with a starter pin even though the loader looks up points by quest ID and Idx1 only. Its exact original definition moves to free index 4, preserving player condition 48140. Before deployment, the migration predicate was corrected to use the actual PlayerConditionID field. Existing coordinate sets are left intact.

The change only affects map guidance. It leaves quest progress, admission, rewards and scenario entry behavior intact. The existing unrelated quest 43568 retains its 22 map points. The other six Mage Tower storylines were outside this route.

After worldserver stopped, the migration was applied to the runtime database. All 78 stored points match the migration and all 45 definitions have coordinates. Readback shows index 2 holds the Legion investigation starter pin and index 4 holds the 12-point search polygon with its original player condition. The world updater will register the migration on the next startup. DBErrors.log had no change during deployment and the crash directory had no files. No separate automated or agent-owned startup test was run during the live gameplay flow. Actual client rendering of the restored markers and regions remains to be checked.
