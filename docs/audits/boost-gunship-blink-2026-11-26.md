The player reported Blink going on cooldown with no displacement on the Horde tutorial ship. The screenshot shows the following Frost Nova lesson. Local 7.3.5 SpellEffect data identifies Blink 1953 effect 0 as leap 29, caster target 1 and forward destination 55. The existing destination code attempted map navigation to a terrain-adjusted position. If that path failed it retained the caster's starting position. The near-teleport packet also calculated a fresh passenger offset for the client while leaving the old offset in server movement data.

Blink on tutorial maps 1554 and 1557 now uses its native forward angle and spell radius with the existing transport ground-path helper. It advances over supported deck sections, respects ship collision and map line of sight, and stops at the last validated point. The ordinary spell still issues the near teleport. No lesson credit is granted here. For same-ship player near teleports that retain the transport, the server now stores the same landing offset that it sends to the client and resolves it against the current ship pose when the acknowledgement arrives. The offset handling excludes vehicle seats.
