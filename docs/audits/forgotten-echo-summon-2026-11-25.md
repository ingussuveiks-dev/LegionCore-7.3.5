# Forgotten Echo summons from Absorb Ancient Knowledge

On November 25, casts of Absorb Ancient Knowledge (241575) during Seeking Lost Knowledge (47067) produced two batches of failed temporary summons for Forgotten Echo (121276). The server recorded 3,582 failures at 12:44:48–49 and 3,704 at 12:46:11–12. The creature template and its SmartAI are present. The core limits nearby summons of the same entry. The earlier world SQL and live MariaDB both contain 3,892 commands for effect zero, exactly 139 copies of each of 28 distinct positions. The runtime's distinct rows match the archived World SQL field for field.

The migration retains one command per original position. The eight-second despawn, the three Remnant target conditions, their separate SmartAI quest credits, and other spell commands are preserved. It keeps the existing introduction and cleanup path for each summoned echo. The baseline and corrected row counts were read from MariaDB using the migration's exact selection. Reapplying the migration selects the same distinct rows. Other duplicated spell scripts found in the same data were outside this change.

The SQL is queued for the next `worldserver` start. The user-owned processes remained running. The production crash directory was empty and DBErrors.log had no append during the data review. Existing server errors were left in the log. The active gameplay workflow deferred separate runtime tests. Live spell casts, the visual at each remnant, and the quest counters after restart still need client verification. The old investigation noted that Remnant 121158 has no static spawn in the live database. The duplicate repair does not infer its spawn or grant objective credit from the summoned echoes.

The same log also contains recurring `Unit::SendMeleeAttackStop` messages between other creature runtime counters. Neither group of counters matches a static creature GUID. The message records a melee stop packet and does not store the template or location, so the actor and script identities remain open. The spell migration leaves those diagnostics intact.
