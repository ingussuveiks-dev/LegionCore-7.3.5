# A Time to Reflect 43323 un 43461

Jubilejas vēsturnieku atjaunošanā atradās divi 1. līmeņa dienas kvesti. Alliance bija piedāvājuma saite, Horde tās trūka, un abi vēsturnieki nevarēja uzdot jautājumu. Atjaunoti abi piedāvājumi, 43 jautājumi ar četriem variantiem no 26124 hotfix datiem, frakciju pilsētu kartes punkti un sākotnējais mērķis `109989`. Atbilžu secība un skaitliskie ID pārbaudīti pret Legion datiem, risinājumi salīdzināti ar tālaika pierakstu.
