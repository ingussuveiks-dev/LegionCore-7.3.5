# Deliverance Point Mage Tower spawns

The current Legion world uses event 400 for both the Magicians' Tower model (gameobject 267785, spawn 126920) and War Councilor Victoria (creature 117871, spawn 12742696). The event was outside its configured 4,319-minute open window when the player visited on November 25. The server reached readiness after the window closed and had not started the event. The player's saved map was 1220 and zone was Broken Shore (7543). The two missing spawns follow shared event state.

Seven Legionfall Laborer placements remained visible in phase 7043 with the tower absent. The matching extracted model for display 40762 was surveyed at its real spawn and orientation. For the seven placements the tower surface differs from the NPC height by 0.083 to 0.377 yards. Bare terrain is 4.0 to 35.3 yards lower. The two phase-7050 banners beside the tower entrance are mounted above the platform, within the tower model's footprint. They also lacked the event link. Two nearby laborers on the ground remain available, including one where the edge of the model overlaps terrain at almost the same height.

The migration links those nine existing static spawns to the same event as the structure and Victoria. Their coordinates and character phase conditions are preserved. The native event loader registers the creatures in the grid while the event is active and removes those event spawns at closure. MariaDB resolved all nine unique candidates with the current native tower and Victoria links. The production binary was already running and no event override was used. This migration is queued for the next user-owned worldserver start. Active and closed client views remain to be checked. No separate runtime or automated gameplay test was run for this user-led flow.

The player had already turned in A Gift From the Six (45866). Thwarting the Twins (46127) starts with Victoria and ends with Archmage Karlain in Dalaran. Raest's Gift (45910) requires the rewarded challenge quest, so its start cannot yet appear. Karlain's Violet Citadel role has the ordinary 7318 phase when the seven Gift From the Six variants are absent from the active log, and 7317 while a variant is active. Both role spawns use the same position. His client visibility at those coordinates has not been verified in this visit.

The world still uses the configured recurring event.
