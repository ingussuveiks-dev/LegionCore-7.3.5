# Deepwind Dunk Brawl

Queue 849 now uses map 1105, the native fifteen-player team capacity and the Deepwind starts stored in build 26972. The last duplicate Gravity Lapse slot now offers Deepwind Dunk. The normal Deepwind Gorge queue continues to use the cart and mine rules.

The Brawl uses the three native home and dropped ball templates and both native basket models. The mine anchors are reused from the matching map. The basket anchors use the native team-base trigger positions. Capture requires a successful interruptible spell on a reserved ball, with range and line of sight checked again at completion. The three native carrier auras are applied through the spell engine. A player carries one ball. Death drops it, leaving returns it, and the return timer restores the home object. The short dunk and ranged shot use the native actions, the enemy basket and a successful cast with a destination. The 100-point basket value is stated in both native tooltips. Player kills count for five. The game uses the 1,500-point objective and the 15-minute limit.
