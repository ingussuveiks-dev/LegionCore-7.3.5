# Charge from the surface inside the Tomb of Tyr

On map 1539 the bed and the swimming surface can both lie under the exact same XY. The ordinary Detour nearest-polygon query sometimes selects a disconnected bed polygon even when the character is swimming at the surface. The fresh path search now retries an incomplete corridor for an actual player swimming at the requested start, off transport, with a measured water or ocean surface and a ground destination. The alternative start must coincide horizontally with the swimmer and match the measured surface height. The retry applies the ordinary traversal filter and only replaces the corridor when it reaches the original destination polygon. Point generation, budget, collision, spell admission and native charge movement use their existing paths.

The TombSurfaceCharge native geometry regression samples the cave on a one-yard grid with deep water, an overhead ceiling, clear model sight to a grounded shore target and a horizontal distance of 10–25 yards. It uses the shipped collision and navigation data and the same retry function as the server. For Shadowlord Slaghammer it found 118 ordinary routes and restored 48 (166/166). For Flesh Spawn it found 115 and restored 68 (183/183). Negative controls cover an unrelated surface height and an undersized corridor buffer. Run tools/research/Read-LegionLegendaryCatalog.ps1 with -SourceFile TombSurfaceCharge.cpp -ProbeName TombSurfaceCharge. These are navigation corridor results; actual player casts, movement packets and final contact in the client await retest.
